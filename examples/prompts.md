# Prompt Examples

These prompts can be copied directly into Codex.

## Planning only

```text
Use $ian-xiaohei-illustrations. Don't generate images yet.
Analyze which parts of this article are worth illustrating and output a shot list of about 5 images.
For each image, specify:
- After which paragraph it goes
- Theme
- Core meaning
- Structure type
- What Xiaohei is doing
- Suggested elements
- Suggested Chinese annotation words

<paste article>
```

## Article body illustrations

```text
Use $ian-xiaohei-illustrations to generate 4 Xiaohei bizarre article illustrations from this article.
Requirements: 16:9 horizontal, pure white background, black hand-drawn line art, sparse red/orange/blue Chinese handwritten annotations.
Each image explains only one core structure—don't make it a PPT infographic or cute cartoon.

<paste article>
```

## Long article illustration strategy

```text
Use $ian-xiaohei-illustrations to create an illustration strategy for this long article.
Don't illustrate evenly—pick only cognitive anchors: core judgments, input-output loops, before/after comparisons, common pitfalls, handoff paths.
Default 6-8 images. Output shot list first—don't generate images.

<paste article>
```

## Single viewpoint, one image

```text
Use $ian-xiaohei-illustrations to generate one 16:9 article illustration for this viewpoint:

Trust isn't shouted out—it's paved over one piece of evidence at a time.

The scene should be bizarre but clean, with Xiaohei taking on the core action.
Maximum 5 Chinese annotations, keep them short.
```

## Workflow theme

```text
Use $ian-xiaohei-illustrations to generate one image for "process one raw material into three types of content: traffic, trust, and conversion."
Don't draw a formal flowchart, and don't recreate the "one fish many uses" example.
Invent a new low-tech metaphor, with Xiaohei participating in the core action.
```

## Edit: Remove title

```text
Use $ian-xiaohei-illustrations to edit this image.
Remove the "Workflow / Flowchart" title and underline in the top-left corner.
Keep everything else unchanged. Don't add any new text or objects.
```

## Edit: Enhance Xiaohei participation

```text
Use $ian-xiaohei-illustrations. The direction of this image is right, but Xiaohei feels decorative.
Keep the core meaning unchanged and regenerate: make Xiaohei the one actually driving the structure's operation.
Make the scene more bizarre, but still pure white, clean, and sparse.
```

## Generate style samples

```text
Use $ian-xiaohei-illustrations to output 5 Xiaohei article illustration effects on different themes.
Themes should cover: information overload, product validation, content compounding, solo company, trust building.
Generate each separately—don't combine into one image.
```
