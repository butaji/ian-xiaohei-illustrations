# Composition Patterns & Originality Rules

## Basic structure types

Choose one structure type; don't mix too many.

### Workflow

Suitable for: Input -> Processing -> Output, content production, AI workflows, automation chains.

Drawing: Input on left, Xiaohei or bizarre machine in middle processing, output on right, orange arrows for main flow direction.

### System partial

Suitable for: Information sources, filters, databases, renderers, agent system sections.

Drawing: Only 3-5 core modules, Xiaohei participates in one key action.

### Before/After comparison

Suitable for: Chaos/order, manual/auto, scattered/converged, anxious/calm.

Drawing: Chaos on left, order on right, orange arrow in middle. Characters can be more exaggerated.

### Role state

Suitable for: User pain points, creator states, too many tools, information anxiety, stuck to running.

Drawing: 2-4 small states, each with a short annotation.

### Concept metaphor

Suitable for: Content factory, information warehouse, mental black box, workflow machine, auto daily reports.

Drawing: One large bizarre object or machine, few inputs, one output. Must be memorable.

### Method layering

Suitable for: Methodology frameworks, system levels, capability stacks, content system layers.

Drawing: Layered boxes, not formal pyramids; Xiaohei carrying bricks or building alongside.

### Map route

Suitable for: Idea to launch, user paths, content handoff paths, learning routes.

Drawing: One curved path, few nodes, Xiaohei pulling lines or walking.

### Mini-comic panels

Suitable for: Failure to success, real process, complaints, before/after changes.

Drawing: 2-4 small scenes, each panel expressing only one action.

## Original metaphor generation method

Always reinvent metaphors from the current article—don't copy old images.

### Three steps

1. Turn abstract concept into a physical action: stuck, leaking, getting heavy, sorting, settling, fermenting, opening, folding, unpacking, backflow.
2. Turn system structure into a low-tech object: broken machine, cardboard box, drawer, water pipe, mailbox, bizarre dial, scale, well, ladder, strange workstation.
3. Have Xiaohei take on the action: not standing beside, but getting stuck in the machine, pulling wrong lines, guarding doors, transporting, fixing, weighing, holding ladders, recording, stuffing things into some bizarre device.

### Usable object pool

- Cardboard boxes, drawers, old machines, funnels, scales, mailboxes, doors, wells, ladders, water pipes, yarn balls, gates, turntables, black boxes, hole punches, pasta machines, clotheslines, strange workstations.
- Use only 1-2 when drawing—don't overfill.

### Xiaohei action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, disassemble, mark, recycle.
- Actions should serve the core meaning—don't be bizarre just for the sake of it.

## Anti-pattern rules

Don't default to opening or recreating `assets/examples/`. These images are only for style calibration: line density, white space, color restraint, Xiaohei temperament.

Unless the user explicitly says "use this one / recreate this composition / modify this case," don't directly reuse these old compositions:

- Conveyor with two breakpoints
- Xiaohei pulling judgment levers inside a content machine
- Xiaohei becoming a funnel sorting traffic/trust/conversion
- Xiaohei cutting material fish
- Xiaohei pulling handoff paths
- Xiaohei pulling three-layer information sources
- Three Xiaohéis holding a speaker / building a bridge / opening doors respectively
- Xiaohei stamping phrase toolbox
- Xiaohei holding signs looking at common pitfalls path

Even for similar themes, invent new metaphors. For example, "handoff path" doesn't have to be a route—could be Xiaohei connecting content tails to door handles; "one fish many uses" doesn't have to be a fish—could be Xiaohei pressing one paper ball into various shapes.
